# 场内公共场地借用与审批管理系统 · 设计系统

## 视觉方向
"医疗青蓝"专业业务系统：高信息密度、强状态辨识、克制的阴影。圆角 6–8px，阴影仅用于抽屉/弹窗，无渐变、无光效、无大面积插画。

## 色彩
| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 | #174A5C | 顶部栏、主按钮、当前菜单、关键数字 |
| 辅助色 | #2A7F86 | 次级按钮、筛选选中态、普通图表系列 |
| 页面背景 | #F3F8F8 | 主内容区背景，表格/表单白底 |
| 强调色 | #316B74 | 链接、信息提示、图表对比系列 |
| 成功 | #247A58 | 已完成、已通过、正常 |
| 危险 | #A62B32 | 驳回、超时、异常、删除确认（小面积） |
| 边框 | #DCE7E7 | 表格线、卡片描边 |
| 次要文字 | #5D7578 | 表头、说明文字 |

状态永不只靠颜色：一律"色块 + 中文标签"。

## 字体阶梯
- 页面标题 20px/600
- 卡片标题 15px/600
- 正文 13px/400，行高 1.6
- 表头 13px/600，表格单元格 13px
- 数字列 `font-variant-numeric: tabular-nums`
- 字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`

## 间距与栅格
- 内容区外边距 24px，卡片间距 16px，卡片内边距 16–20px
- 左侧菜单 220px，顶部栏 56px，内容区自适应
- 表单标签 100–120px，单列输入 360–520px，搜索下拉 180–240px

## 组件规格
| 组件 | 规格 |
|---|---|
| 按钮 | 高 32px，左右内边距 14px，圆角 6px；主按钮 #174A5C 白字；次按钮白底 #174A5C 描边 |
| 输入框 | 高 32px，边框 #DCE7E7，聚焦边框 #2A7F86 + 2px 淡青外圈 |

| 卡片 | 白底，1px #DCE7E7，圆角 8px，无阴影 |

## 布局规则
- 管理端：220px 侧边栏（深色 #174A5C + 白色文字）+ 56px 顶栏（白底 + 面包屑/消息/头像）+ 内容区
- 申请人端：门户风格，白色顶栏 + 内容流 + 场地卡片网格
- 1440×900 首屏不出现纵向滚动（看板）
