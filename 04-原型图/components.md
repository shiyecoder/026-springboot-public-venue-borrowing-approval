# 组件规范

## 按钮
- 主按钮：背景 #174A5C，文字 #fff，高 32px，圆角 6px，左右 14px，hover 亮度 +6%
- 次按钮：白底，#174A5C 1px 描边
- 危险按钮：白底 #A62B32 描边文字，仅用于驳回/删除/停用，且必须二次确认
- 表格行内最多"查看 + 2 个高频操作"，其余进"更多"菜单

## 表单
- 标签宽 100–120px，右对齐；必填项前加红色 *
- 单列输入 360–520px；搜索下拉 180–240px；数字输入右对齐 + tabular-nums
- 新增/编辑用右侧抽屉（560px），关闭前检测未保存内容
- 复杂表单提供"保存草稿"

## 表格
- 表头背景 #F0F6F6，行高 44px，无固定列宽，`min-width` 按内容自适应，超宽横向滚动
- 编号 / 状态 / 日期 / 操作列单行不换行
- 空状态："当前筛选条件下无记录，清空筛选或新建场地借用申请"
- 加载 >300ms 显示表格 loading 或骨架，禁止整页白屏

| 状态 | 样式 |

| 已驳回 / 超时 / 异常 / 缺货 | 红底 #F7E7E8 / 文字 #8f2429 |

## 卡片与抽屉
- 卡片白底 1px #DCE7E7 圆角 8px，内边距 18px，无阴影
- 抽屉宽 560px，右侧滑入，阴影 `0 8px 24px rgba(23,74,92,.16)`，底部固定操作区
- 弹窗宽 520px，圆角 8px，同上阴影

## 分页
右对齐，显示总数；每页 10 / 20 / 50；切换筛选后回到第 1 页。

## 图表
- 线图主色 #2A7F86，柱图 #174A5C / #2A7F86 / #316B74 三色循环
- 图表区白底卡片，标题 13px/600
- 同一含义跨页面颜色一致；图例文字 11–12px #5D7578
